# Tasks

*Read each task aloud as written. Start timing when you finish reading. Outcome codes on the sheet:*

| Code | Meaning |
|---|---|
| `S` | Success, unaided |
| `P` | Partial: part of the goal |
| `H` | Succeeded after the hint |
| `F` | Fail: gave up, or 2 more minutes after the hint |

| # | Read aloud | Success when | Time | Hint after 2 min stuck |
|---|---|---|---|---|
| T1 | "Help the tribe stay warm." | The Stone Age fire is lit (by a blink/lightning on the fire pit) | Seconds to first meaningful action; seconds to lit fire | "The game talks about blinking. What could a blink do here?" |
| T2 | "Make sure the tribe has food." | Food delivered to the fire: a mammoth hunted or a haunch cast | Seconds | "Look at what the tribe is doing when they're hungry." |
| T3 | "Get the tribe to the next age." | The Stone Age objective is complete and the next era starts | Seconds; number of fail/retry screens | "What does the top bar say you still need?" |
| T4 | "Open the panel that shows how the game reads you, and tell me what it shows." | Opens Model (M) and explains, in their own words, that the game is learning *their* signals | Seconds; quality of explanation (0 none, 1 partial, 2 clear) | "Is there a button about a model?" |
| T5 | "That run is over. Do whatever you'd like to do next." | They **choose** to start another run (that's replay intent; don't push) | Yes/No; time to first meaningful action in run 2 vs run 1 | none (not hinted) |
| T6 | "Turn the camera off and carry on for a minute." | Plays on with the camera off; the game stays playable | Seconds to find the camera control; any blocker | "Where are the camera settings?" |

## Optional tasks (if time allows; note them as T7+)

- **T7: zoom out.** "Find out what's beyond this island." Success: they zoom out to the globe or galaxy (scroll, Z or the zoom buttons) and back.
- **T8: civ sandbox.** "Start the sandbox with four civilisations and tell me what's going on." Success: they explain at least two civs, contact, or war.
- **T9: 3D.** "Try the 3D view, then tell me whether you'd keep it on." This is the #93 readability check: note whether they can still tell the people, fire and objectives apart.

## Meaningful action

The first input that changes the game state on purpose: a blink aimed at something, holding calm or focus during a prompt, or a cast. Random key mashing doesn't count.
